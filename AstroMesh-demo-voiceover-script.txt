AstroMesh is an autonomous orbital safety simulation built to make multi-agent collision response visible and verifiable. Here, sixteen satellites and sixty-four debris objects share the orbital scene. A selected spacecraft encounters several approaching objects at once. The mission supervisor raises the alert, and shared orbital memory passes telemetry and prior decisions to the team. The Satellite Worker calculates a compound thruster maneuver. Before execution, the Adversarial Verifier independently checks predicted separation, fuel, burn duration, and safety constraints. Once approved, the thrusters fire and the satellite shifts onto a safer path. The event stream records each handoff, decision, and verification as it happens. Across these eight test encounters, the simulation reports eight of eight avoidance cases passed, with mission metrics and agent latency visible alongside the 3D view. Crusoe Managed Inference supports live agent reasoning, while physics checks keep the maneuver measurable. AstroMesh demonstrates how agents can coordinate, explain, and verify safer orbital decisions.
